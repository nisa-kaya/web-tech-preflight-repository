# Kampüs Etkinlikleri - Sprint 1

Bu proje, Web Teknolojileri eğitimi kapsamında yalnızca **HTML ve Git** kullanılarak hazırlanan Kampüs Etkinlikleri uygulamasının ilk sprintidir. Projede CSS ve JavaScript kullanılmamış olup, tamamen anlamsal (semantic) HTML etiketleri ve yerleşik tarayıcı stilleri tercih edilmiştir.

## Canlı URL
Projenin Vercel üzerinden yayınlanan canlı sürümüne aşağıdaki bağlantıdan ulaşabilirsiniz:
👉 **[Canlı Proje Bağlantısı](https://web-tech-preflight-repository-brbq.vercel.app/)**

## Proje İçeriği ve Sayfalar
Proje 5 temel sayfadan oluşmaktadır ve aralarında eksiksiz bağlantılar bulunmaktadır:
1. **index.html (Ana Sayfa):** Etkinliklerin listelendiği ana sayfa.
2. **etkinlik-detay.html:** Seçilen bir etkinliğin detaylarının (afiş, tarih, yer, kontenjan vb.) gösterildiği sayfa.
3. **etkinlik-ekle.html:** Yeni etkinlik eklemek için gerekli form alanlarını barındıran sayfa.
4. **etkinlik-guncelle.html:** Mevcut etkinlik bilgilerini güncellemek için önceden doldurulmuş form alanları içeren sayfa.
5. **.gitignore ve README.md:** Proje yapılandırma ve dokümantasyon dosyaları.

## Kullanılan Teknolojiler
* HTML5 (Semantic Etiketler: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<dl>`, `<form>`)
* Git & GitHub (Versiyon Kontrolü ve `sprint-01` etiketi)
* Vercel (Canlı Yayına Alma)
